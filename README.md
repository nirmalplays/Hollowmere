# Hollowmere (working title)

Isometric pixel-art Souls-lite action RPG in Godot 4.3+ (GDScript). Solo first, optional co-op later.
Design docs: [GAME_PLAN.md](GAME_PLAN.md), [STORY_BIBLE.md](STORY_BIBLE.md).

## Run
Open the folder in Godot 4.3+ and press F5, or: `godot --path .`

## Test
- All tests (headless): `godot --headless --path . res://tests/test_runner.tscn` (exit code 0 = pass)
- Some tests: `godot --headless --path . res://tests/test_runner.tscn -- unit m2_combat`
- Screenshot a scene (windowed): `godot --path . --script res://tools/dev/screenshot.gd -- res://scenes/world/greywood_glade.tscn out.png 60 move_right:5:40`

## Look and art
Isometric 2D pixel art in a Dimraeth-style high 3/4 view, rendered at 640x360 and scaled up crisply.
Art comes from free, properly licensed packs (CC0 / CC-BY-SA / MIT / OFL), pixelized to one style by
`tools/art/`. Sources and licences: [ASSETS.md](ASSETS.md). Screenshot: `docs/screenshots/greywood_glade.png`.

## Art
Placeholder art is generated by Python scripts in `tools/art/` (needs `pip install pillow`). Re-run `gen_player.py`, `gen_tiles.py`, then `gen_preview.py`.

## Renderer
Compatibility (`gl_compatibility`) for broad desktop support. Viewport 480x270, integer scaling, Nearest filtering.

## Milestone log
- **M0 (done):** project skeleton, pixel settings, folder layout, autoload stubs (EventBus, DataRegistry, GameState, NetManager, SaveManager), full InputMap, boots to a main menu.
- **M1 (done):** Solo Game opens a test room built from `data/rooms/test_room.tres`. 8-direction movement with acceleration/friction, 4-direction animated 16x24 player (generated art), wall collision, camera with room limits, lantern light, F3 debug overlay, Esc returns to menu, pixel UI theme.
- **Visual overhaul (after M2):** switched to an isometric world (Dimraeth-style camera). Characters (8 directions, full animation sets) from Flare (CC-BY-SA), environment from CC0 packs (KipperFalcon forest/cave, isometric trees, dark ruins, props and tents), all pixelized to one look. First area: the Greywood glade (ruined shrine, dead Hollow grove, camp, plateau, pond) with the Hollow Husk training enemy. All M0–M2 systems and tests carried over.
